## 规范（每篇 P 文档的骨架）

```
# P{n} {主题}（提纯版）
> 生成日期 / 用途(D几精读) / 阅读法（先 5 分钟速查卡 → 概念层 → 实现层按需）
## 📍 本页定位与蒸馏溯源（每篇必写，先回答"我在哪、从哪来、为什么这样提纯"）
   ① 在整体计划中的位置：对应 Day / 主轴位置 / 配套 P 文档 / 建议读法
   ② 被蒸馏文档明细：文档总数 + 主干清单（每个源 1 行：内容→提炼点），
      数量多时给主干明细并注明"全集见 §0 源文件清单表"
   ③ 蒸馏理由与方法（100-150 字）：每个文档大概讲什么 → 连在一起主要
      说明什么 → 因此怎么提纯（重组逻辑）——知其然且知其所以然
## 0 定位与源文件清单        （源路径 ↔ 提炼点 ↔ ↳深挖?）
## 1 概念层                 （统一类比 + 全景图/表 + 因果链 + "面试怎么说"）
## 2 实现层                 （代码/notebook 结构提纯：关键函数/协议/伪代码 + 为什么）
## 3 工程层                 （避坑 + 生产取舍）
## 4 面试卡                 （问题 → 答案要点 → 仓库出处；先自答再看）
## 5 5 分钟速查卡           （终极压缩）
```
